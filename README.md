# HostPL-comparer

DXF図面とULKESパーツリスト（PL）から機器符号（Reference Designator）を抽出し、
図番ごとに突き合わせて差分を出力するStreamlitアプリ。

## できること

- **DXFファイルから直接**機器符号を抽出する（複数ファイル可）
- **ULKES PLファイル**から機器符号を抽出する（複数ファイル可、1ファイル内の全アセンブリを自動検出）
- 図番が一致するもの同士を突き合わせ、**機器符号と個数**の差分をABC順に出力する
- DXF側・ULKES側それぞれの機器符号リストをプレビューし、テキストファイルとして保存する
- 比較結果を色分けExcelとしてダウンロードする
- 表記ゆれ（DXFの改行・仕様注記の括弧、ULKES側の入力揺れ等）を吸収して比較する
- 「指定領域で比較する」オプションで、DXF側のラベルを領域（「特定」「除外」）で絞り込む
  （ULKES側は常に図番の全部品）

## セットアップ

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 使い方

1. DXFファイル（複数可）とULKES Excelパーツリスト（複数可）をアップロードする
   - 同名ファイルが複数選択された場合は最初の1件のみを採用する
2. （必要なら）「指定領域で比較する」をONにし、「領域を検出」→「領域一覧」で比較したい領域を
   「特定」、外したい領域を「除外」にチェックして「領域選択を完了」を押す。「特定」した領域の内側の
   ラベルだけを比較し（「特定」領域が無い図面は図面全体）、「除外」した領域の内側は除く
3. 「比較」ボタンを押す（処理中は進捗メッセージが表示される）
4. 結果セクションに、比較サマリー・警告・図番ごとの比較結果パネルに続けて、
   「ULKESのみに存在する図番」・「部品リストがないULKESの図面番号」・
   「複数回記載されているULKESの図面番号」（後の2つはいずれもファイルごと、
   ファイル名ABC順）・「図面枠を検出できないDXFファイル」が表示される
   - 各パネル内でDXF側・ULKES側の機器符号リストをプレビューでき、
     「テキストファイルを保存」ボタンで個別に出力できる
5. 画面最下部の「比較結果をダウンロード」ボタンから、色分けExcelを一括ダウンロードできる

### 図番の決まり方

- **DXFファイル**: ファイル名から拡張子を除いた部分をそのまま図番として扱う
  （例: `EE6312-000-01A.dxf` → `EE6312-000-01A`）。照合させるにはファイル名を
  図番と一致させておく必要がある（図面データからの図番抽出は行わない）
- **ULKES PLファイル**: 「図面番号」列の値をアセンブリ番号（図番）として扱う。
  部品展開のない図番（他アセンブリの参照行のみ）は比較対象から除外し、
  ファイルごとに一覧表示する

## 差分の色分け

| 区分 | 色 |
|---|---|
| 図面のみ | 薄いピンク |
| ULKESのみ | 薄い青 |
| 両方にあるが個数が不一致 | 薄い黄 |
| 両方にあり個数も一致 | 薄い緑 |

「図番ごとの比較結果」の見出しにマウスを乗せると、この色分けの説明が表示される。
